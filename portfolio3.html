The story of LFS I will write about how I installed LFS (Linux From Scratch). Linux From Scratch is basically an operating system that you build yourself. You won't need to code it yourself, but you will need to pick out the packages that you want/need. However, with Linux From Scratch, there is a guide that tells you exactly what you need and what there is to do. I started with the prerequisites list and learned about them. After that, I knew what a tarball is and how to unpack it. The next step was to prepare the host system for the LFS installation. After that, I needed to build all the necessary tools and then build the LFS system. After that, I needed to configure things about the system and compile the kernel. But uh-oh, in the next step, I needed to add the partition to GRUB and boot into it. Everything went well—I even saw the partition in the GRUB menu—but when selecting it, there was an error instead of the LFS installation. I tried to fix it and also went back to compiling the kernel, but it was no use. It just didn't work. I was a little bit sad, but not really, because I mostly picked this project to listen to podcasts without needing to think since in the process, there was a lot of compiling and waiting time where I was able to listen to the podcast.
